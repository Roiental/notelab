1.1.2 Building OpenSSL

$ wget https://www.openssl.org/source/openssl-1.1.1g.tar.gz
$ ./config \
--prefix=/opt/openssl \
--openssldir=/opt/openssl \
no-shared \
-DOPENSSL_TLS_SECURITY_LEVEL=2 \
enable-ec_nistp_64_gcc_128
$ make depend
$ make
$ make test
$ sudo make install
$ cd /opt/openssl
$ sudo rmdir certs
$ sudo ln -s /etc/ssl/certs

1. 2. 1  키 생성
TLS 서버 실행을 준비하는 첫 번째 단계는 개인 키를 생성하는 것입니다
키 알고리즘
OpenSSL은 RSA, DSA, ECDSA, EdDSA 키 알고리즘을 지원하지만, 실제로 모든 알고리즘이 유용한 것은 아닙니다. 
예를 들어 DSA는 더 이상 사용되지 않고 EdDSA는 아직 널리 지원되지 않습니다. 
따라서 인증서에 사용할 수 있는 알고리즘은 RSA와 ECDSA뿐입니다.

genpkey
$ openssl genpkey -algorithm RSA -out privatekey.pem -aes-128-cbc -pass pass:hello -pkeyopt rsa_keygen_bits:2048
$ $ openssl pkey -in fd.key -text -noout
